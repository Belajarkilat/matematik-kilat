# Matematik Kilat - Roblox Edition

**Interactive Math Learning Game for KSSR Grades 1-6**

A Roblox-inspired educational game built with React + Vite, featuring:
- 🎮 Roblox-style UI with floating blocks, particles, and hard drop-shadows
- 👤 Avatar customization (blocky SVG avatars with skins, hats, outfits)
- 🌍 Game world hub with 6 tahun (grade) islands
- 📚 900+ math questions across 30 chapters
- 👥 Multi-profile support (no progress collisions on shared devices)
- ⭐ Scoring, streaks, badges, and leaderboard tracking
- 💾 Full offline support via localStorage
- ☁️ Optional Firebase cloud sync (flagged off by default)

## Quick Start


### 2. Extract Questions (One-time)
The app needs the 900 math questions extracted from the published Artifact. Run:

This pulls questions from the live Matematik Kilat app at:
`https://claude.ai/code/artifact/7e2870d2-a3f5-4362-aaf0-f5c6ba03389e`

```bash

```

Opens at `http://localhost:5173` — app runs fully offline with localStorage persistence.

## Features

### 🎮 Game World Hub
- 6 island nodes (Tahun 1-6)
- Avatar stands on current tahun
- Click an island to see its 5 chapters

### 📚 Chapters & Levels
Each tahun has:
- **5 chapters** (math topics per KSSR)
- **3 sub-levels** per chapter: Mudah (Easy) → Sederhana (Medium) → Cabaran (Hard)
- **10 questions** per level = 30 per chapter = 150 per tahun

### 👤 Avatar Customization
Blocky SVG avatar with:
- **Skin color** (6 tones)
- **Face style** (happy, cool, thinking)
- **Hat type** (none, cap, crown, beanie)
- **Outfit color** (accent color)

Saved per-profile → no collisions when multiple kids play on same device.

### 📊 Progress & Scoring
- **Multi-profile localStorage** (key: `bk_matematik_roblox_profiles_v1`)
- Tracks: questions attempted, correct answers, streaks, badges
- Automatic streak/combo counter during quiz (like Matematik T2 Kilat)
- **10 unlockable badges**: first-question, speed-demon, perfect-score, etc.

### ☁️ Firebase Integration (Optional)
Currently **disabled by default** (set `VITE_USE_FIREBASE=false` in `.env`).

To enable cloud features:
1. Create a Firebase project at https://console.firebase.google.com
2. Copy credentials to `.env` (see `.env.example`)
3. Set `VITE_USE_FIREBASE=true`
4. Configure Firestore security rules (see `MATEMATIK_KILAT_PROJECT_SETUP.md`)

## Troubleshooting

### "Cannot find module 'tahun1.json'"
Run `npm run extract-questions` first. This generates the question files.

### "localStorage is not available"
App checks for localStorage availability. In private/incognito mode, you may see warnings but the app still works (uses memory fallback).

### "Firebase credentials missing"
Leave `VITE_USE_FIREBASE=false` (default) to run offline. Cloud features are optional.
